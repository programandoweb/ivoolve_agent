# Documentación de Ivoolve Agent

Esta carpeta es parte del sistema de trabajo, no documentación opcional.

## Estructura

- `architecture.md`: arquitectura vigente.
- `learning/`: explicaciones didácticas.
- `decisions/`: decisiones arquitectónicas (ADR).
- `progress/`: bitácora cronológica de trabajo.
- `setup/`: instalación y ejecución.

## Regla

Antes de modificar código, revisar progreso reciente y decisiones relacionadas.

Después de una tarea relevante, registrar exactamente:

- qué se hizo;
- por qué;
- qué archivos cambiaron;
- qué se probó;
- qué falta.
