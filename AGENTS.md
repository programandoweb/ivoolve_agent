# Instrucciones para agentes de desarrollo

Antes de modificar este repositorio:

1. Leer `Agent.md`.
2. Leer la documentación del área afectada.
3. Leer los últimos registros de `docs/progress/`.
4. Revisar decisiones relacionadas en `docs/decisions/`.
5. Implementar el cambio más pequeño posible.
6. Documentar el progreso antes de dar la tarea por terminada.

Este repositorio también contiene agentes de IA ejecutables dentro de `agents/`.
No confundir este archivo de metodología de desarrollo con los archivos `agents/<nombre>/Agent.md`.
