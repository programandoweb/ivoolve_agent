# Registro de progreso

Cada tarea relevante debe crear el siguiente número disponible.

Formato sugerido:

```text
NN-descripcion.md
```

Debe incluir:

1. Fecha
2. Objetivo
3. Contexto
4. Decisiones
5. Alcance
6. Archivos afectados
7. Cambios realizados
8. Pruebas ejecutadas
9. Resultado
10. Riesgos
11. Fuera de alcance
12. Pendientes
13. Siguiente paso
